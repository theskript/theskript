## Public work

- [hold-and-confirm](https://github.com/theskript/hold-and-confirm): a seat hold, a simulated payment provider and one recording function that confirms a payment exactly once when notifications are lost, repeated, late or out of order. 65 tests, including a seeded random simulation, and no dependencies.
- [accessible-data-explorer](https://github.com/theskript/accessible-data-explorer): a keyboard and screen-reader accessible table, chart and live region on invented data. 60 tests with axe-core and jsdom, and contrast checked by a script.
- [audit-gate](https://github.com/theskript/audit-gate): a CI step that fails on high and critical dependency advisories but accepts dated exceptions that expire. 74 offline tests, no dependencies.
- [engineering-playbook](https://github.com/theskript/engineering-playbook): seven short working templates for onboarding, review, releases, incidents, mentoring and decisions, with 21 tests that check structure and links.

- [approved-edits](https://github.com/theskript/approved-edits): a small command-line tool where a person approves each text change before it is applied, backed up and checked. Seven tests, no dependencies.
- [ask-the-portfolio](https://github.com/theskript/ask-the-portfolio): a Nuxt 4 question-answering app with local embeddings, cited answers and refusal when it has no answer. Fourteen unit tests and an evaluation script.
- [release-plan](https://github.com/theskript/release-plan): a plan, apply, verify and rollback method for releasing a built folder onto a target folder, on sample data. Read-only plan, a reviewed plan id that apply must match, backups, a ledger, tests, no dependencies.
- [evidence-gated-build](https://github.com/theskript/evidence-gated-build): a refuse-by-default compiler for an invented layout format, with a corpus, a canary and a numeric verifier, and in-sample and held-out results reported separately. Tests, no dependencies.

All eight are demonstrations with no client or employer material. Each README states what was measured and what was not.
